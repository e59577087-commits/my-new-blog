# 学习页面“研习案卷”实施计划

对应规范：`docs/superpowers/specs/2026-07-11-study-dossier-design.md`

## 任务 1：建立学习页构建回归测试

**文件**

- 新建：`scripts/study-index.test.mjs`
- 修改：`package.json`

**步骤**

1. 测试前在文章目录创建临时学习文章，覆盖：仅 `学习中`、仅 `已整理`、同时包含两个状态、无状态、状态标签带首尾空白、缺少可选字段。
2. 运行 Astro 生产构建并读取 `/study/index.html`。
3. 添加失败断言：
   - 页面具有专属 `data-study-dossier` 结构，不再使用 generic catalog。
   - 完整副标题为“仙人抚我顶（并非挠自己头）”，且删除线只包裹括号内文字。
   - `已整理` 优先于 `学习中`。
   - 无状态文章默认归入正在研习。
   - 首尾空白不影响状态识别。
   - 状态标签不出现在普通主题标签列表。
   - 总数和正在研习数量正确。
4. 读取学习页组件源码，断言整体空状态“卷帙待启”和两个分组的小型空状态存在。
5. 在测试清理阶段删除临时文章。
6. 在 `package.json` 增加 `test:study` 命令。
7. 运行测试并确认因专属结构尚不存在而失败。

## 任务 2：实现标签归类与学习页标题

**文件**

- 修改：`src/pages/study.astro`

**步骤**

1. 保留 `getPublishedBySection("study")` 数据入口。
2. 对每篇文章的 tags 执行 `trim()`，识别 `学习中` 和 `已整理`。
3. 按“已整理优先、无状态默认学习中”拆分 `ongoing` 和 `completed`。
4. 计算总文章数和正在研习数。
5. 将标题改为主标题“学习”和完整副标题；只在“并非挠自己头”外包裹删除线 span。
6. 移除旧 generic catalog 与 `EntryCard` 引用，将两个数组传给学习页专用组件。

## 任务 3：实现研习案卷组件

**文件**

- 新建：`src/components/StudyDossier.astro`

**步骤**

1. 组件接收 `ongoing` 与 `completed` 两组文章。
2. 当两组都为空时，仅输出完整空状态“卷帙待启”。
3. “正在研习”输出语义化案卷卡片列表：封面、状态题签、标题、description、日期、category 和主题标签。
4. “已成篇章”输出无大封面的语义化归档列表：完成日期、category、标题、description 和主题标签。
5. 过滤 `学习中`、`已整理` 状态标签，不把它们重复渲染为主题标签。
6. 任一分组为空但另一组有内容时，输出该分组的小型空状态。
7. 所有文章条目使用现有 URL、日期格式和封面回退工具。

## 任务 4：添加专属视觉与响应式样式

**文件**

- 修改：`src/styles/global.css`

**步骤**

1. 为 `.study-index` 添加青墨与旧纸金栏目变量，并提供深色主题值。
2. 为副标题删除线设置细线、继承颜色和适当偏移；不改变现有 `.section-subtitle` 基础风格。
3. 添加案卷卡片、归档列表、状态题签、主题标签和空状态样式。
4. 桌面端案卷使用一至两列宽卡，归档保持单列高扫描性。
5. 手机端全部单列，长副标题自然换行，封面缩窄，统计移动到标题下方。
6. 添加 hover、focus-visible、明暗主题与 reduced-motion 兼容；装饰线不进入辅助技术阅读顺序。
7. 不修改随笔、分享、首页和文章详情样式。

## 任务 5：完整验证

```powershell
npm run test:study
npm run test:sections
npm run test:obsidian
npm run test:toc
npm run test:external-links
npm run build
```

目视检查：

1. 无学习文章时的“卷帙待启”。
2. 桌面与手机的副标题换行和删除线范围。
3. 两种状态分组、状态优先级与普通标签。
4. 浅色与深色主题的青墨、旧纸金和文字对比。
5. 键盘焦点、长标题、缺少封面与缺少 description 的布局稳定性。

最后运行 `git diff --check`，确认没有提交测试临时文章、构建产物、日志或无关文件。
