# Obsidian 文章图片宽度

## 目标

让 Obsidian 图片嵌入语法的宽度在博客文章中可靠生效：`![[图片.jpg]]` 默认显示为 150px 宽，`![[图片.jpg|120]]` 显示为 120px 宽。普通 Markdown 图片保持现有行为。

## 设计

- `remarkObsidian` 只为 `![[...]]` 图片节点生成尺寸属性；未写尺寸或尺寸格式无效时使用默认宽度 150px，合法的 `|宽度` 与 `|宽度x高度` 继续使用声明值。
- 图片灯箱保留现有点击放大能力。缩略图触发器读取图片的 `width` 属性，并通过 CSS 自定义属性让外层容器采用同一宽度，避免当前固定 `18rem` 的容器覆盖编辑器尺寸。
- 缩略图宽度始终受正文可用宽度限制，在窄屏上可缩小但不会横向溢出。
- 未经过 Obsidian 插件生成的普通 Markdown 图片不获得默认宽度，继续按原图尺寸和现有文章样式展示。

## 验收

- `![[图片.jpg]]` 生成 `width="150"`，页面缩略图宽度为 150px。
- `![[图片.jpg|120]]` 生成 `width="120"`，页面缩略图宽度为 120px。
- `![[图片.jpg|120x90]]` 保留宽高声明，页面缩略图按 120px 宽展示。
- 普通 Markdown 图片 `![说明](图片.jpg)` 不被强制设为 150px。
- 所有缩略图在正文宽度不足时不会溢出，并仍可点击查看大图。
- 图片解析、文章内图片和灯箱相关测试以及项目构建通过。
