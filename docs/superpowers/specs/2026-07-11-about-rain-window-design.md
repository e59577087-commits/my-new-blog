# 关于页全屏雨夜统计设计

## 目标

将关于页收敛为一个只有雨夜视频与站点统计的沉浸式首屏。`public/雨夜小猫.mp4` 铺满整个页面，访客不再阅读自述、标题或状态文案，只通过四项数据感知这个小站的积累。

## 页面结构

页面只包含两个视觉层：

1. 全屏雨夜视频背景；
2. 一张小型、无明显边框的雾面统计卡。

不再渲染页面标识、主标题、自述、在线信号、左右分栏、实体窗框、格栅、窗台、植物或额外内容章节。

## 视频背景

- 视频覆盖关于页完整首屏，使用 `object-fit: cover` 和可调 `object-position` 保证小猫可见。
- 视频区域向上延伸到透明站点导航栏背后，容器高度为完整 `100svh`，顶部不得露出页面背景色或白条。
- 站点导航内容继续显示在视频上方并保持可交互。
- 视频使用 `autoplay muted loop playsinline`，不显示控件、不自动播放声音。
- 首次进入时，视频在约 1.2 秒内从轻微模糊和低亮度过渡到清晰。
- 视频加载前和播放失败时显示 `public/雨夜小猫-poster.webp`。
- 页面使用轻量主题遮罩：浅色模式为偏亮雾层，深色模式为蓝黑雾层；遮罩不得明显损害小猫主体。
- 视频上方不添加重复渐变雨痕或斜线动画，仅保留色调、反射和主题遮罩。
- `prefers-reduced-motion: reduce` 下不自动播放视频，直接显示 poster，关闭视差和入场动画。

## 统计卡

统计卡位于桌面端右下安全区域，宽度随视口变化但不超过约 34rem。卡片不绘制明确边框，使用半透明主题背景、轻量背景模糊和轻阴影与视频分离。背景模糊约为 `0.4rem`，饱和度约为 `110%`；底色不透明度略高于原方案，确保文字与动态视频保持稳定层次，同时仍能隐约看到视频轮廓。

卡片只展示四项数据：

- 已发布文章数量；
- 站点访问次数；
- 站点运行天数；
- 已发布文章正文总字数。

桌面端四项横排；手机端使用两列两行。统计卡内部不再嵌套另一层卡片背景。

视频清晰后，整张统计卡以一次淡入和轻微上移出现。统计数字保持静态，不做递增动画；视频循环不会重新触发卡片动画。

## 字数统计口径

总字数在构建阶段从 `getPublishedArticles()` 返回的正文计算，因此自动排除草稿和 Frontmatter。

- 中文、日文和韩文统一表意文字按单个字符计数；
- 连续的拉丁字母或数字按一个词计数；
- Markdown 标记、HTML 标签、链接目标地址和纯标点不计数；
- 结果使用中文本地化千位分隔显示，标签为“正文总字数”。

字数计算应放在独立工具函数中，并具有直接单元测试，不把解析逻辑塞进页面模板。

## 响应式

- 桌面端统计卡位于右下，避开页头、页脚和视口边缘；视频本身延伸至页头背后。
- 手机端视频仍铺满首屏，统计卡移动到底部安全区域并改为 `2 × 2`。
- 极窄屏允许统计卡自然增高，不得出现横向滚动。
- 视频裁切需要分别验证桌面与手机，确保小猫没有被关键裁切。

## 主题与可访问性

统计卡的背景、文字、弱化文字、分隔线和强调色全部使用现有主题语义变量。视频作为氛围素材标记为装饰性内容；缺失视频不会丢失统计语义。

统计区域使用适当的语义分组和可理解标签。纯装饰雨痕与遮罩不进入辅助技术阅读顺序。

## 组件边界

- `about.astro` 获取已发布文章、计算文章数量与总字数，并组织全屏结构。
- `AboutRainWindow.astro` 只负责全屏视频、poster、色调、反射、主题遮罩、视差与视频状态。
- `StatsCard.astro` 接收文章数量与总字数，继续负责访问次数和运行天数，并提供全屏关于页专用的浮层变体。
- 字数统计函数放在 `src/utils` 中，可独立测试与复用。

## 验证

- 全屏视频覆盖关于页并延伸至透明导航栏背后，顶部没有页面背景白条；
- 统计卡仅包含四项数据，桌面横排、手机 `2 × 2`；
- 已发布文章数量与总字数正确，草稿不参与统计；
- 中文、英文、Markdown 链接和代码标记的计数符合定义；
- 视频先清晰，统计卡后淡入，视频循环不重播动画；
- 明暗主题下统计卡均清晰且没有明显边框；
- 统计卡雾化轻盈，文字清晰，背景视频不会被揉成大面积亮雾；
- reduced-motion 和视频失败时 poster 正常；
- 视频上方没有重复渐变雨痕或规律斜线；
- 所有专项与回归测试通过，`npm run build` 成功。

## 非目标

本轮不增加自我介绍、建站故事、兴趣卡片、时间线、背景音乐、播放器控制、Canvas 粒子或多屏滚动叙事。
