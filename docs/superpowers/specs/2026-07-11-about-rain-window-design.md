# 关于页雨夜窗景首屏设计

## 目标

将当前内容单薄的关于页改造成一个单首屏、具有明确视觉个性的沉浸式页面。页面以“雨夜独处——隔着窗与世界相望”为情绪核心，使用 `public/雨夜小猫.mp4` 作为窗外景象，在不增加长篇内容的前提下，让访客首先记住页面氛围。

## 范围

本轮只实现一个完整首屏，不增加建站故事、兴趣卡片、时间线或页面级音频。

首屏包含：

- 右侧标题、简短自述和站点在线状态；
- 右侧现有 `StatsCard` 统计信息；
- 左侧无边框、保留玻璃氛围层的视频雨景；
- 首次进入动画、轻量指针视差和无障碍降级；
- 桌面与移动端响应式布局。

## 页面构图

### 桌面端

页面主体限制在一个视口高度内，在站点页头和页脚之间形成左右分栏。

- 左栏约占 58%–62%，放置无边界视频雨景。
- 右栏约占可用宽度的 38%–42%，作为昏暗的室内区域。
- 标题、自述、在线状态和统计卡从上到下排列；统计卡保留现有数据来源，但样式需要适应左栏宽度。
- 视频使用 `object-fit: cover` 填满玻璃区域，构图优先保证小猫可见。
- 视频区域不添加外框、横竖格栅、窗台、植物或其他实体窗户装饰，只保留低对比度玻璃反光、暗角和雨痕，避免遮住小猫主体。
- 桌面端视频区域从网格基准向左扩张约 32–64px、向上和向下各扩张约 24–40px；右边界、文字栏位置和两栏间距保持不变，并保留少量页面安全留白。

### 移动端

移动端改为上下布局：视频雨景在上，文字与统计在下。页面允许自然纵向滚动，不强行压缩到一个物理屏幕内，也不裁切统计内容。

视频雨景保持稳定的横向画面比例并适当增加高度，不使用负向水平扩张。动画持续时间缩短，指针视差不启用。

## 内容

首屏主文案采用克制的短句，不写成个人简历。

- 页面标识：`ABOUT · LIGHT RAIN`
- 主标题：`我在这里，留下一点回声。`
- 自述：沿用站点现有语气，表达“记录随笔片段、喜欢的东西和慢慢整理好的生活小事”。
- 状态：展示 `haven, for you` 的在线信号式标识。
- 统计：复用当前 `StatsCard`，文章数继续由 `getPublishedArticles()` 提供。

最终实现可以微调标点和换行，但不得扩大为多段介绍。

## 动画与交互

### 首次进入顺序

动画在每次完整进入关于页时播放一次；同一次页面停留期间不重复播放：

1. 页面从安静的暗场开始。
2. 右侧窗框与视频先出现。
3. 视频在约 1.2 秒内从轻微模糊、低亮度过渡到清晰。
4. 窗景稳定后，左侧页面标识、标题、自述、在线状态和统计卡依次淡入并轻微上移。
5. 整套入场动画在约 2.2–2.6 秒内完成，完成后保持稳定状态。

动画不得因页面滚动或指针移入而重复触发。

### 持续交互

- 桌面端指针移动时，窗框前景与视频产生幅度很小的差速位移，制造空间深度。
- 玻璃雨痕以独立、低对比度的缓慢动画移动。
- 交互不得形成追逐鼠标的强烈效果，也不得改变视频播放进度。
- 统计数字保持静态，仅随统计卡整体参与依次淡入，避免与窗景争夺注意力。

## 组件边界

- `about.astro` 负责获取文章数量、组织首屏布局和传递内容。
- 新的雨夜窗景组件负责视频、玻璃氛围层和视差逻辑。
- `StatsCard` 保持独立并复用现有数据接口；仅在必要时增加适应窄栏的样式能力。
- 页面专属样式优先与页面或窗景组件放在一起，避免把大量关于页规则继续堆入全局样式。

窗景组件不读取文章数据，也不控制统计卡；关于页不直接管理逐帧视差细节。

## 视频与降级

视频元素使用 `autoplay muted loop playsinline`。不提供自动播放声音，也不显示原生播放控件。

- 视频加载期间显示与整体色调一致的深蓝雨夜占位背景。
- 视频播放失败时保留无边框占位背景，页面文案与统计仍可正常使用。
- 实现时从视频截取一张 poster 图，用于加载前、移动端策略和无动画模式。
- 当前视频约 26 秒、7.8 MiB。原型允许直接使用；正式收尾时评估压缩至约 3–5 MiB，前提是不明显损害雨景和小猫的细节。
- 对启用 `prefers-reduced-motion: reduce` 的用户，关闭入场位移、雨痕动画和视差，并使用 poster 静态画面代替自动播放视频。

## 主题与可读性

关于页外围背景完全复用全站 `--page-background`，标题、正文和弱化文字使用现有主题语义变量。浅色模式保持与其他页面一致的清透背景，深色模式使用全站暗色背景；只有视频区域维持雨夜暗色，并在靠近文字的一侧用柔和渐变融入页面。统计卡继续使用现有深浅色玻璃体系，文字对比度必须满足可读性要求。

所有纯装饰层使用 `aria-hidden`。视频作为氛围素材，不承载独立信息；其缺失不会丢失页面语义。

## 验证

实现完成后至少验证：

- 桌面宽屏和常见笔记本尺寸下，首屏构图完整且统计卡位于右侧；
- 手机窄屏下，文字、统计卡和窗景按顺序自然排列，无横向滚动；
- 小猫在 `object-fit: cover` 后仍处于可见区域；
- 首次入场严格遵循“窗景先清晰、左侧内容后显现”的顺序；
- 动画不会重复播放；
- 明暗主题下文字均清晰；
- `prefers-reduced-motion` 下不播放持续动画；
- 视频加载失败时占位背景正常，页面内容仍完整；
- `npm run build` 通过。

## 非目标

本轮不实现多章节关于页、完整个人履历、建站时间线、兴趣抽屉、背景音乐、Canvas 粒子系统、复杂滚动叙事或视频播放器控制界面。
