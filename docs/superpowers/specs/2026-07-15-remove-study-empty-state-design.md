# 移除学习页空状态文案

## 目标

当站内没有已发布的学习文章时，学习页不再显示 `STUDIUM`、`卷帙待启` 和“案头尚静，待第一则求知札记落笔。”这组空状态文案。

## 设计

- 保留学习页现有的页头、简介与文章数量统计。
- `ongoing` 和 `completed` 均为空时，`StudyDossier` 不渲染任何可见内容，也不保留空状态容器。
- 存在学习文章时，正在研习与已成篇章的现有展示保持不变。

## 验收

- 零篇学习文章时，生成的学习页中不存在上述三段空状态文字。
- 零篇学习文章时，不输出 `data-study-empty` 或空的 `study-dossier` 容器。
- 存在学习文章时，现有分组与文章卡片仍正常渲染。
- 项目相关测试与构建通过。
