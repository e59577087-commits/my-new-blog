# 随笔与分享页面差异化设计

## 背景与目标

当前 `/tools/`（随笔）和 `/share/`（分享）使用相同的标题结构、`EntryCard` 与 catalog 网格，除文案和数据源外几乎没有区别。此次改版需要让两个栏目呈现明显不同的阅读气质，同时继续属于同一个 haven 博客设计系统。

内容定位固定为：

- 随笔：私人日记、情绪与生活故事。
- 分享：教程、资源与可复用的经验总结。

成功标准是读者进入首屏即可辨认栏目属性；两页在导航、字体、基础色彩、圆角和动效上仍保持品牌一致；新增文章不需要手工维护页面结构。

## 设计方向

采用“编辑部双人格”方向：

- 随笔使用偏暖的编辑感和纵向时间线，强调时间、个人口吻与叙事节奏。
- 分享使用偏冷的资料库感和紧凑知识卡片，强调分类、摘要与快速扫描。
- 两页使用栏目专属固定布局，不响应全站文章列表的 list/grid 外观偏好，避免差异被全局布局覆盖。
- 所有新样式基于现有 CSS 变量并适配明暗主题，不引入新依赖或独立视觉系统。

## 随笔页

### 栏目头部

- 主标题使用“生活近况”。
- 副标题保持自然、个人化的口吻。
- 显示简短栏目统计：已发布随笔数量及最近更新月份。
- 头部保持克制，不使用大幅 Hero，避免当前文章数量较少时显得空洞。

### 时间线

- 已发布的 `section: essay` 文章按日期倒序排列。
- 文章按年份和月份分组，年份/月分隔符构成纵向时间线的主要结构。
- 每个条目展示日期、标题、description、标签和小型封面。
- 最新一篇通过轻微的尺寸、边框或强调色差异突出，不改变整体信息结构。
- 条目整体可点击，并保留清晰的键盘焦点状态。

### 响应式行为

- 桌面端日期与正文信息可形成左右层级。
- 手机端收为单列，日期移到标题上方，时间线装饰不挤压正文。
- 超长标题正常换行；标签过多时换行，不截断主要内容。

## 分享页

### 栏目头部

- 主标题使用“实用内容库”。
- 副标题说明这里收录教程、工具、资源和经验总结。
- 头部可显示已发布分享文章数量，但不使用夸张统计组件。

### 自动标签筛选

- 从所有已发布的 `section: share` 文章的 `tags` 自动生成筛选项。
- 标签需要去除首尾空白、排除空值、按首次出现顺序去重。
- 固定提供“全部”选项，并默认选中。
- 新增或删除分享文章标签后，在下一次静态构建和部署时自动更新筛选项，无需修改页面代码。
- 草稿文章的标签不参与筛选项生成。
- 当某个标签不再被任何已发布分享文章使用时，该筛选项自动消失。
- 点击筛选项后在客户端即时显示匹配文章；一个文章包含目标标签即可匹配。
- 筛选按钮支持键盘操作，并使用 `aria-pressed` 或等价状态表达当前选择。

### 知识卡片

- 使用稳定、紧凑的资料库网格，不单独放大第一篇文章。
- 每张卡片展示内容类型、标题、description、标签和更新时间。
- 内容类型优先使用 `category`；未填写时使用稳定的栏目回退文案，不要求新增 frontmatter 字段。
- 卡片整体可点击，悬停与键盘焦点反馈沿用现有动效语言。

### 响应式行为

- 桌面端根据可用宽度显示多列卡片。
- 手机端改为单列；标签筛选栏允许横向滚动，同时保持可见的焦点样式。
- 筛选不得造成页面横向溢出或卡片高度剧烈跳动。

## 数据与组件边界

- 页面继续通过现有文章工具函数获取已发布文章。
- 随笔页负责日期分组；分享页负责标签聚合和初始筛选数据。
- 新建两个职责单一的栏目组件：随笔时间线组件与分享资料库组件。现有 `EntryCard` 保留给首页或其他通用列表，不强行扩展成多个互斥变体。
- 客户端筛选仅控制分享卡片的可见状态，不引入后端、搜索服务或第三方状态库。
- 文章详情页、首页和站点导航不在本次改动范围内。

## 空状态与回退

- 栏目没有已发布文章时，展示符合栏目语气的空状态，不保留空白网格。
- 分享筛选无匹配结果时，展示提示并提供返回“全部”的操作。
- 缺少封面时继续使用现有 `coverOrDefault` 回退逻辑。
- 缺少 description、category 或 tags 时卡片仍保持完整布局，不输出空标签容器。
- 日期无效属于内容校验错误，继续由现有内容 schema 或构建流程报告，不在页面中静默伪造日期。

## 视觉与可访问性

- 随笔使用现有设计变量派生的暖色强调；分享使用冷色强调。文本和交互控件在明暗主题下均满足清晰对比。
- 装饰性时间线不进入辅助技术的阅读顺序。
- 筛选、卡片和空状态操作均可通过键盘完成。
- 尊重现有 reduced-motion 设置；动效只用于说明筛选和悬停状态，不承担信息传递。
- 页面结构使用正确的标题层级、列表语义和可读的链接名称。

## 测试与验收

自动测试覆盖：

- 随笔按年份/月正确分组并保持日期倒序。
- 分享筛选标签从已发布文章自动生成、清理空白并去重。
- 草稿标签不进入筛选项。
- 标签筛选正确显示多标签文章。
- 无文章、筛选无结果、缺少可选 frontmatter 字段时显示正确回退。
- 两页不再复用通用 catalog 标记，且具有各自的关键结构和可访问状态。

完成后运行现有测试与生产构建，并在桌面和手机视口目视检查：首屏栏目辨识度、长标题、标签换行、暗色主题、键盘焦点、筛选结果和图片回退。

## 明确不做

- 不增加全文搜索、分页、后端筛选或持久化用户筛选状态。
- 不新增必须填写的 frontmatter 字段。
- 不重新设计文章详情页、首页或全站导航。
- 不添加新的 UI、图标或动画依赖。
