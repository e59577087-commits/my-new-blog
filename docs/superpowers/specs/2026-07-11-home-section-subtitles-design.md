# 首页栏目副标题统一设计

## 目标

首页随笔、分享、学习三个栏目目前使用独立的临时副标题“小事小事。”“好东西好东西。”“研究研究。”。此次调整将首页文案与对应栏目页保持一致，并复用已经建立的古风副标题视觉语言，同时保持首页更紧凑的层级。

## 文案映射

- 随笔：`浮生拾遗`
- 分享：`任君采撷`
- 学习：`仙人抚我顶（并非挠自己头）`

学习副标题中：

- 括号属于副标题正文并保留。
- 只给“并非挠自己头”添加删除线。
- “仙人抚我顶”和括号本身不加删除线。

删除以下首页旧文案：

- `小事小事。`
- `好东西好东西。`
- `研究研究。`

## 结构与样式复用

- 保留首页现有三个栏目标题、查看全部链接、条件渲染和文章卡片结构。
- 每个副标题使用 `section-subtitle home-section-subtitle` 两个类。
- `section-subtitle` 继续提供现有中文书卷气字体、次要文字颜色、字重、字距与 `-6deg` 轻微右倾。
- `home-section-subtitle` 只覆盖首页需要的紧凑尺寸：
  - 响应式字号约 `0.78rem–0.88rem`。
  - 缩小主标题与副标题间距。
  - 字间距略小于栏目页，避免学习副标题过长。
  - 保持可换行，不截断、不横向溢出。
- 学习副标题继续复用 `study-subtitle-strike`，不复制删除线样式。

建议标记：

```html
<h2>随笔</h2>
<p class="section-subtitle home-section-subtitle">浮生拾遗</p>
```

```html
<h2>分享</h2>
<p class="section-subtitle home-section-subtitle">任君采撷</p>
```

```html
<h2>学习</h2>
<p class="section-subtitle home-section-subtitle">
  仙人抚我顶（<span class="study-subtitle-strike">并非挠自己头</span>）
</p>
```

## 响应式与可访问性

- 三个栏目标题继续使用 `<h2>`，副标题使用普通段落，不改变页面标题层级。
- 副标题颜色使用现有 `var(--color-muted)`，自动兼容深色模式。
- 学习副标题在窄屏可自然换行，删除线范围不因换行改变。
- 静态倾斜和删除线不涉及动画。
- 学习栏目仍只在存在已发布学习文章时出现在首页；本次不改变该条件。

## 实现范围

- 修改 `src/pages/index.astro` 中三处副标题标记与文案。
- 修改 `src/styles/global.css`，新增一个紧凑的 `.home-section-subtitle` 修饰规则。
- 不创建新组件，不重构三个栏目区块。
- 不修改随笔、分享、学习栏目页自身，不修改卡片、分隔线和查看全部链接。

## 测试与验收

添加首页构建断言，验证：

- 三个新副标题在存在对应栏目文章时输出。
- 三句旧文案不再输出。
- 三处均使用共享基础类和首页修饰类。
- 学习副标题删除线只包裹括号内文字。
- 首页紧凑修饰样式包含目标字号、间距、字距和换行约束。

完成后运行首页/栏目测试、所有现有测试与生产构建，并检查桌面与手机、浅色与深色主题下的标题层级和长副标题换行。

## 不做事项

- 不改变首页栏目是否显示的条件。
- 不修改首页卡片布局或栏目间距。
- 不新增字体、依赖、组件或动画。
