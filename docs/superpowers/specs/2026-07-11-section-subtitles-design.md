# 随笔与分享页面副标题设计

## 目标

精简随笔与分享页面的标题区域，删除偏功能化的英文 kicker、替代性主标题和说明段落，恢复清晰的栏目主标题，并在其正下方加入古风、文艺且低调的中文副标题。

## 文案

随笔页面：

- 主标题：`随笔`
- 副标题：`浮生拾遗`

分享页面：

- 主标题：`分享`
- 副标题：`任君采撷`

删除以下现有标题区文案：

- `JOURNAL / 随笔`
- `生活近况`
- `一些最近常出现在生活里的小东西，也包括那些让我哭笑不得的时刻。`
- `LIBRARY / 分享`
- `实用内容库`
- `整理教程、工具与走过弯路后留下的经验，方便需要的时候快速找到。`

右侧文章数量、更新时间和主题数量统计保持不变。

## 结构

- 两个页面当前没有共用标题组件，只复用 `.section-intro` 样式。
- 为保持最小改动，不新增组件；两个页面各自保留语义化 `<h1>`，并在其正下方加入 `<p class="section-subtitle">`。
- 两个页面共用同一 `.section-subtitle` 样式，避免重复 CSS。
- 标题和副标题继续作为 `.section-intro` 左侧标题组，右侧统计结构不变。

## 副标题视觉样式

- 字体优先复用项目已加载的 `LXGW WenKai`，并提供 `Kaiti SC`、`STKaiti`、`KaiTi`、`FangSong`、`STFangsong`、`Noto Serif SC`、`STSong`、`SimSun` 与通用 `serif` fallback。
- 字号使用响应式 `clamp()`，桌面和手机均明显小于主标题，目标约为主标题的三分之一。
- 字重为 `400`，不使用粗体。
- 字间距约 `0.16em`，形成中文题签或诗句的舒展感。
- 颜色使用 `var(--color-muted)`，沿用现有明暗主题变量。
- 使用 `transform: skewX(-6deg)` 与左侧变换原点形成轻微右倾；不使用更大的倾角，不添加额外旋转。
- 副标题为 `inline-block`，避免 transform 影响整行布局。
- 主标题与副标题之间保留紧凑但可辨认的垂直间距。

## 响应式与可访问性

- 主标题仍是页面唯一的 `<h1>`，副标题使用普通段落，不扰乱标题层级。
- 手机端副标题字号与字间距略微收紧，避免四字短语造成横向溢出。
- 倾斜仅为静态排版，不涉及动画，不受 reduced-motion 设置影响。
- 统计区域沿用现有断点，在窄屏移动到标题组下方。
- 不新增字体文件或网络字体请求。

## 测试与验收

更新栏目页面构建测试，验证：

- 随笔页输出主标题“随笔”和副标题“浮生拾遗”。
- 分享页输出主标题“分享”和副标题“任君采撷”。
- 六段旧标题区文案不再出现在对应页面。
- 两页仍输出原有统计内容。
- 两个副标题都使用共享 `.section-subtitle` 类。
- 全局 CSS 包含书卷气字体 fallback、次要文字颜色、`400` 字重、字间距和 `-6deg` 轻微右倾。

完成后运行栏目页测试、其余现有测试与生产构建。目视验收桌面/手机、浅色/深色主题下的标题层级、倾斜自然度和统计区域对齐。

## 不做事项

- 不修改时间线、分享筛选、卡片、导航或文章详情页。
- 不创建新的标题组件。
- 不改变右侧统计数据或计算方式。
- 不引入新字体文件、字体依赖、图标或动画。
