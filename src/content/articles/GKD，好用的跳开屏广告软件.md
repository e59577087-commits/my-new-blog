## 闲聊

第一次看到 GKD 的时候，我确实被惊到了。当时闲着无聊，就在 GitHub 上随便翻项目：搜索 APK，再按 Star 数排序。翻了没几页，我居然看到了坤坤头像（~~谁这么无聊~~）。更意外的是，它还是一个拥有这么多 Star 的中文项目，于是我当场就下载试用了。

实际使用下来，GKD 确实是个好东西，配得上这么多 Star。它是一款基于规则自动跳过开屏广告和重复操作的 Android 工具。

## 安装

官方安装指南在这里：<https://gkd.li/guide/>。![[Screenshot_20260714_162948 1.jpg|100]]

在下载页面选择最新正式版 APK（撰写时为 v1.12.1），下载后安装并打开即可。

GKD 需要无障碍权限才能正常工作。这个权限可以读取界面内容并执行点击等操作，比较敏感；请只从官方渠道下载，并根据自己的需要授权。页面下方也有基础使用说明，这里就不重复了。遇到问题可以留言或者询问 AI。

## 导入规则

自己写规则确实麻烦，好在可以直接导入别人维护的订阅。

这里使用的是 Lin-arm 维护的第三方订阅项目：<https://github.com/Lin-arm/GKD_subscription>。它不是 GKD 官方订阅，而是原项目停更后的社区续更 Fork。仓库 README 明确写着“禁止在国内平台传播”，发布或转载前请先阅读项目声明并自行判断。

订阅规则可能误触，开启过多也可能增加耗电或拖慢触发。这个项目默认只启用“开屏广告”类规则，其他规则需要手动开启；建议按需开启，不要一次打开全部规则。

导入步骤：

1. 打开 GKD 的“订阅”页面，点击右下角的 `+`。
2. 复制订阅链接 <https://gkd667.vv.ax/gkd.json5>，粘贴到输入框。![[Screenshot_20260714_165555 1.jpg|100]]
3. 点击“确定”完成导入；成功后会看到新的订阅。![[Screenshot_20260714_170634.jpg|100]]
4. 点进刚导入的订阅，再选择“应用规则”。![[Screenshot_20260714_172317.jpg|100]]
5. 根据自己的需要开启或关闭各应用规则。![[Screenshot_20260714_172533.jpg|100]]
