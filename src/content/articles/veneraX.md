## 闲聊
最近有个好哥们问我有啥好的漫画软件推荐，问对人了。本人也喜欢看漫画，碍于财力有限，所以找过很多所谓的免费漫画软件，发现很多软件要看广告（这种其实挺恶心的，大部分免费漫画软件，看的那些免费漫画的漫源其实是来自别人无偿提供在网站上，结果被拿去赚广告钱。）
说个题外话，这个软件其实是venera的作者自己的fork版，原版已经停更了，似乎是被举报了。有能力的还是希望你支持正版漫画，国内画漫画的大哥哥过得还是比较艰难的，唉，我有好多喜欢的漫画都停更了。。。
## VeneraX 是什么

简单说，VeneraX 是一个用 Flutter 写的漫画阅读器，支持 Android、iOS、Windows、Linux、macOS。

它本身不提供任何漫画，也不自带任何站点内容。真正决定它好不好用的，是它的**漫画源（Comic Source）**机制：每个源就是一个 JavaScript 文件，告诉 App「数据从哪拿、图片怎么解析」。你把源加进去，它就能像浏览一个漫画网站一样去搜索、看分类、看排行、追更、下载。
（你就当他是个浏览器，只不过是专门用来搜索漫画的。）
# 安装

先给链接：

- 项目地址：<https://github.com/Kyosee/VeneraX>
- 下载页：<https://github.com/Kyosee/VeneraX/releases>

注意一点：**VeneraX 没有上 F-Droid**，也没有别的商店渠道，Android 只能从 Releases 页面下 APK 手动安装（别相信浏览器里的独立venera网站，软件原作者只在github上发布）。以目前最新的 v2.3.3 为例：

| 平台                      | 文件                                                                                                        |
| ----------------------- | --------------------------------------------------------------------------------------------------------- |
| Android（通用）             | `VeneraX-2.3.3.apk`（79 MB，兼容性最好）                                                                          |
| Android（arm64）          | `VeneraX-2.3.3-arm64-v8a.apk`（31.6 MB，现在的手机基本都选这个）                                                        |
| Android（armv7 / x86_64） | `VeneraX-2.3.3-armeabi-v7a.apk` / `VeneraX-2.3.3-x86_64.apk`                                              |
| Windows                 | `VeneraX-2.3.3-windows-installer.exe` 或免安装的 `VeneraX-2.3.3-windows.zip`                                   |
| macOS                   | `VeneraX-2.3.3+246.dmg`                                                                                   |
| Linux                   | `VeneraX-2.3.3-amd64.deb` / `VeneraX-2.3.3-arm64.deb`，Arch 用户可以直接下 `VeneraX-2.3.3-246-x86_64.pkg.tar.zst` |
| iOS                     | `VeneraX-ios-2.3.3+246.ipa`（需要自己签名，不能直接装，这点要有心理准备）                                                        |

装好之后 Android 和 Windows 版会自己检查更新，不用每次回来翻 Releases 页面。

## 添加漫画源（重点）

装好之后打开 App，你会发现它是空的——因为还没有源。这一步是整个软件的灵魂。

### 用现成的源仓库

点开软件，点击漫画源，然后点来源库。

![[VeneraX-ab52bc13.jpg|120]]![[VeneraX-673a57d5.jpg|191]]


随便命名，把下面这个地址填进去，然后点添加，再点一下你添加的这个库，会出现很多漫画源，选择你要添加的（其实可以全部添加，但是有几个用不了的，不过不会影响软件正常使用。）

```
https://cdn.jsdelivr.net/gh/venera-app/venera-configs@main/index.json
```
这是 [venera-configs](https://github.com/venera-app/venera-configs) 官方维护的源列表镜像，里面目前有 30 多个源，包括 MangaDex、拷贝漫画、包子漫画、Komiic、再漫画、漫画柜、Lanraragi、Komga、Kavita 等等，本地漫画库类的（Komga、Kavita、Lanraragi）也在里面。

![[VeneraX-ae11dde5.jpg|129]]![[VeneraX-7de1f45e.jpg|127]]![[VeneraX-85d4812d.jpg|132]]

填好之后 App 会把这个列表拉下来，你在列表里勾选想要的源，点应用/导入，源就加进去了。之后回到首页，就能看到搜索、分类、排行、探索这些页面全都活了。

### 自己写一个源
假如上面的漫源库不能满足你，或者发现了一个更好的漫画网站，你也可以自己做一个漫画源。我的建议是没必要自己去折腾，直接把那个漫画网站的网址丢给ai，让他帮你写一个适用于veneraX的漫画源，让他手把手教你添加。

## 小tips
1. 有时你可能会遇到各种各样的漫画源方面的问题，比如提示你需要进行Claudeflare验证，老老实实点一下然后进行验证就行，还有有些源是需要开梯子的，或者有些源的规则已经不适用了，需要进行更新，你也可以截个图问ai该怎么修。如果上面方法都不行，那只有一个可能，那个漫画源的网站没了，对，物理意义上的没了（说到这，又让我想起了伤心事，漫画源列表里不是有个嗨皮漫画吗，这是一个非常优质的漫源，画质也好，更新也快，可惜原站主已经删库跑路了，大抵是被警告了吧，我才爽用了一个月，唉，偏我来时不逢春。。。）
2. **作者本人的要求**。VeneraX 是作者自用的 fork，风格比较随性：没有商店渠道，更新节奏也不保证。另外它的用户协议里明确写了，**不要到微博、微信公众号、X 这类公开平台去宣传推广这个项目**——自己用、小圈子交流没问题，真想感谢就点个 star，别到处转发。
3. 有问题可以去问问ai（尽量别问豆包。。。）
