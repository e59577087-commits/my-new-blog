## 控制对比度

暗色界面的重点是控制对比度。正文需要足够清晰，辅助文字可以降低亮度，边框用于建立结构，但不应该抢走内容注意力。

## 保持阅读优先

技术博客的首页不需要营销式大图和复杂动效。更重要的是让读者快速理解作者关注什么、最近写了什么、还能去哪里继续阅读。

```css
body {
  background: #0f1115;
  color: #e8edf4;
  line-height: 1.8;
}
```

## 组件化带来一致性

组件化之后，文章卡片、工具条目和页面标题都能保持一致，这比堆叠装饰更能产生稳定、专业的观感。
